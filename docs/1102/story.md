# Source-backed city item sales

Imported city characters can sell an unambiguously identified original carried
item or part of its stack, finish the trade, and use ordinary SAVE as SAV.
The remaining object keeps its named fields and identity relations. Native
continuation retains the source basis for another sale and school training.

## As built

Immutable source-container ordinals identify objects, not code/price or archive
byte offsets. Each removal records its preceding training count; Commit marks
the last removal of one Sell. Several pack clicks therefore refresh load once.
SalesVersion1 is separate from city-import policy. Published WIP SalesVersion0
lacks proven Sell grouping and remains native-only/retired.

Load refresh compares signed stored load/capacity quotients before and after
updating load from own weight plus the signed container accumulator. Only a
changed quotient calls full Human derive and spellbook refresh. No equipment
modifier reconstruction runs. Native LOAD independently reconstructs the source
baseline and replays operations before validating the actual current member.

Whole sales remove unreachable objects before identity reminting. The actual
archive reference walk retains shared children still reachable from live actors.
Repeated SAV/AGS conversion does not shift surviving keys a second time.
No simulation byte-form change or source SAV blob is added.
