# Command acknowledgments

## Intent and authority

Map commands must have optional spoken confirmations. Add the Acknowledgments
checkbox to Sound Options, persist it across process starts, and keep the
command independent of voice admission. Use VIDEO-SFX-053/054 after their
published knowledge adoption for the stored option, acceptance copy and
3000-millisecond response threshold. The owner authorizes this fidelity slice.

## Scope

One living owned human answers a submitted map gesture. Use installed command
recordings for male/female mages, hero fighters and hired fighters. The option
does not mute dialogue, hurt sounds or music. Voices follow the speech channel.
Each speaker has a presentation-only clock and sample cycle, reset with the
viewer. A silent or missing sample never cancels a command or changes saved state.

The checkbox stages its change until OK; Escape discards it. Failed persistence
keeps the dialog and previous live value. Other existing Sound Options controls
retain their own transaction policy. Missing preferences enable acknowledgments.

Exact original voice-family assignment, candidate priority, random distribution,
selection-only and special-command responses remain declared debt. Installed
filenames support the authored family mapping, not a claim of full original
selection parity. Track selection and Random Order remain later work.

## Proof

Focused tests discriminate delivery before one group reply, missing command
sinks, per-speaker timing at 2999/3000 ms, new-viewer reset, missing samples,
six authored families, failed writes, cancel/accept, cold preferences and an
unchanged world hash. The EN/RU installed tests pass: all eighteen human command
recordings decode to nonzero PCM, the checkbox persists, and fresh viewers emit
one command reply when enabled and none when disabled. The existing channel
release test verifies the expanded panel and paused world.

The sound-options executable witness includes these map pointer scenarios and
reads concrete speech-player activity when a device is present. Actual executable
results, the sole adversarial review and final merge gates belong to the seat
receipt and journal. Native original input and human listening remain unobserved.
