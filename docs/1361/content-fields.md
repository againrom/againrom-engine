# Selected SAV fields

[content-fields.json](content-fields.json) assigns a source answer to each scoped
full field in the mission, town and entry contexts. Its namespaces remain
separate: decoded ordinary fields, physical framing/transport fields, typed
extension members and unwitnessed catalog selectors. Their counts are not added.
The inventory contains descriptors, selected answers, component references,
reasons, authorities and hashes. SAV bytes and decoded values remain external.

For each `files[]` record, `spaces.decoded`, `spaces.file` and `spaces.typed`
contain rows `[owner_field_index, selected_decision_index, components]`.
Resolve the owner through the matching `owner_field_keys` namespace and its
answer through `selected_decisions`. Each component names a `component_scopes`
index and selected decision, with an optional historical candidate reference.
The `columns` contract defines those indices. `unwitnessed_schema` keeps the
catalog/context selectors outside the emitted populations.

Each owning field selects CURRENT, RULE or DEBT exactly once. Atomic arrays count
as one field. Independent Body/Base/Modifier presence and known masks remain
separate source components. A field with any debt component selects DEBT. All
current components select CURRENT. A current/rule composition selects RULE only
with the complete operands and pinned claims; its components remain visible.
Multiple current sources are not merged into one unexplained source label.

CURRENT requires the named pre-export carrier and exact subject join for the
selected value. Equality alone does not join an actor or structure. RULE names
its operands and pinned claim. An unproved constructor, generic engine policy,
missing source or unmeasured guard is page-backed DEBT. Unknown meaning and
missing known state are separate reasons. A selected retention/default fallback
is not independent proof of the current value.

A is a measured known output loss. B is measured equality with incomplete source
proof; only its counts by structure are reported. C names 37 semantic families
and 39 residual subspans with format pages. C is independent of source selection:
known raw history can preserve a field whose gameplay meaning is Unknown.
Unmeasured comparisons and missing operands/joins are outside A/B/C, and remain
explicit. A0 and B0 are bounded to the measured obligations.

Fresh normal route files and Hero matrices use the frozen work07 inputs and
source bytes. The nine measured Hero/pool/period/regeneration losses are closed
by actual RED/GREEN controls. The city matrix covers cold LOAD, next SAVE, entry
and ticks. Potion tests retain assertion logs; no persistent potion SAV hashes
are claimed. Maintained skill 130 is distinct from effective skill 100.

Historical source answers apply only to their named frozen observations. They
are not promoted to fresh source proof without an exact descriptor/subject match.
Every unobserved catalog template/context remains explicitly selected as DEBT;
these selectors describe schema/lifecycle limits and do not imply emitted fields.
A finite inventory is not universal gameplay or source completeness.

The story's three rows link the context records and selected components. The
external source freeze, input/capture hashes and receipts bind the observations.
The review candidate also carries separate clean-SHA checks. No full M2, final
chain, original-runtime write or landing follows from this inventory alone.
