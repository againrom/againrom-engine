# Imported city conversion

## Result and contract

An eligible imported city crosses SAV → AGS → a fresh process → SAV without
the source path or source bytes. Ordinary SAVE after that AGS load uses the same
explicit original-export seam. Native and world saves remain native; explicit
SAV export refuses unsupported state and never substitutes AGS.

The additive snapshot member holds a versioned semantic city model, indexed
object references, stable-party bindings and original eligibility baselines.
Absent provenance remains the zero/default state for older AGS. No simulation
byte-form change was needed. Malformed provenance fails before session
publication; object counts, member lengths, references and allocation depth are
bounded. Aliases and backreferences remain semantic relations, not copied SAV
records. Changes to Human values, items or roster remain outside the proven gate.
LOAD reconstructs eligibility baselines from the semantic source through the
same party importer and selected table/body context, before installing any
session. A persisted baseline assertion cannot authorize changed Human values.
State DTO version 2 stores path-sorted records; legacy version-1 maps decode
and normalize without hiding nested allocations from the gob preflight.

`saveconvert` requires explicit input, output, target format and asset root. It
preserves the source label unless overridden, never mutates input, never replaces
an existing output, and publishes only complete validated output atomically.
Both formats fence the configured asset root and detected install ancestors,
including aliases, before creating directories and again before publication.
SAV import in this tool is limited to eligible no-world cities, not the existing
partial mission importer.

malformed/future/bounded provenance and transactional restore pass. The lawful

crosses two processes before production LOAD/SAVE. Exact measurements and

members do not establish complete live spellbook semantics; that is separate
