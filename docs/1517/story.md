# Traps, unit spells and casting structures without a template

## Intent

A map maker adds a trap, a unit spell entry or a casting structure on any first-game map, including one with no type-9 record. A casting structure's power and scan range are editable. Unit spells and casting structures bind to their object by id, so shipped casting structures off their building's anchor cell edit and copy like any other.

## Authority

The knowledge pin moves from k352 to k353. ALM-EDITT9-328 gives the original editor's constructor and the three Add routes. ALM-T9WORD-329, ALM-T9WORD-330 and ALM-T9WORD-331 give the trap element's word 2: unwritten stack residue in the original, 9078 or 9396 in every shipped trap, read by the game only on the linked zero-cell arm. ALM-EDITCAST-332 and ALM-T9CAST-333 give the casting structure's spinner ranges, unchecked typed entry and the game's low-8-bit reads. ALM-T9BIND-334 and ALM-T9BIND-335 give binding by the id dword and the shipped off-anchor population (158 of 206 EN, 49 of 60 RU). DLG-PAGES-091 and DLG-PAGES-092 give the pager rule. The k353 partial retractions of ALM-SAVE-253 (`+0x12` is on the wire) and ALM-T9TAG-312 (the building is found by id) are read; DIV-3248 names the first, and no row or test cites the second. Story 1514's claim set stands.

## As built

The type-9 codec's one Add route, `AddSpellFrom`, takes a template value. A record index copies that record, as before. A `SpellConstructor` value names a kind (trap 0, unit spell 8, casting structure 4) whose record the codec builds: 26 zero bytes with the kind, and for a trap two elements. The route then writes the cell and the id, and the Add window's other values are fields of the new record, as for every Add kind. On the wire a new trap is tag 0, cell, kind From + 2 x To, id 0 then the typed id, spell, power, two elements at the trap's cell with word 2 = 0 (DIV-4045). A new unit spell is tag 0, cell, kind 8, unit id, spell, power, no element. A new casting structure is scan range, cell, kind 4, structure id, spell, power, no element. A copy keeps every other byte of its template, including element word 2.

The Add window's template step offers New trap, New unit spell and New casting structure before the map's records. Two optional steps follow power: the trap's source and target kind, asked only for a trap, and the scan range, asked only for a casting structure. A host marks a step that does not apply as Absent (`InspectionNewStep.Absent`); the step list stays data in `addKinds`.

A casting structure's fields are spell, power 0..255 and scan range (`+0x00`) 0..255. Trap and unit spell power stays 0..100. A value outside a field's range is refused through the popup with the field's label and range, and writes nothing (DIV-4046). Unchanged shipped values, power 150 and 200 in `Beast.ALM` and scan range 0, open, show and save byte-equal.

The object check `checkScriptReference` gains a binding mode: a cell spell's id is looked up among units by unit id and among structures by the id word sign-extended, as `rom.exe` keys them; no cell is compared and the hero band is not exempt. The anchor-cell rule is gone. A unit spell or casting structure whose id names no object is listed with an unbound mark; it offers no field and refuses every edit, and Delete or spell 0 removes it. Add of a casting structure already recorded on the same cell with the same id updates that record, as in story 1514; another cell of the same structure appends a second record, as the original editor does.

Deleting a structure or a unit deletes the cell spells bound to it, as the original editor's delete does (ALM-EDITDEL-299 item 3): a structure takes every casting record (kind 4) whose id is its sign-extended id word, a unit every spell entry (kind 8) whose id is its unit id. `deleteObject` (`pkg/game/mapinspectioncasts.go`) is the one delete of the record popup's Delete and of a selection's Delete. It deletes the object, then each record from the highest index down, through the record codec's `Delete` with its item link renumbering (ALM-EDITLINK-298), and folds them into one history entry, so one Undo restores every byte. Item recipes (cell 0,0) are not among them. A record that lost its object another way, by a change of the structure's script target id or in a map made elsewhere, stays unbound and is removed by Delete or spell 0. Add takes any cell for a casting record or a unit spell entry; the original writes one only on a cell of its object (DIV-4048).

The game pager is unchanged.

## Proof

Focused tests on the records fixture, a map with no type-9 record: `TestEditorCellSpellsAddWithoutATemplate` adds a trap, a unit spell and a casting structure off its anchor through the Add window's keys and compares each record with the constructor rule byte by byte, then undoes to the original bytes. `TestEditorCastingStructureFieldsStopAt255` writes power and scan range 0 and 255 through key and pointer Apply, compares the whole map with the one changed field, and refuses 256 with a message and no changed byte. `TestEditorCellSpellsBindByIdAlone` edits and copies a casting structure off its anchor, and checks that an unbound casting structure and an unbound unit spell are listed as unbound and refuse field, edit and Add. `TestEditorObjectDeleteTakesItsCellSpells` deletes a structure with two casting records and a unit with a spell entry by Delete on the selected record, then both by a Shift drag and the selection popup's Delete button; each time the bound records go, the trap and two item recipes stay byte-equal, the ground sacks' recipe links fall by the records removed below them, and one Undo restores the map's bytes. `TestEditorUnboundCellSpellDeletes` unbinds a casting record by changing its structure's script target id through the popup, checks that it offers no field and takes no edit, and removes it by Delete and by spell 0, each undone to the same bytes. Both fail on `dc9df109`. `TestCellSpellConstructorRecords` checks the codec's constructor bytes and refusals. `TestEditorNativeCellSpellUsesAddBuilder` drives native Update from F3 to AddRecord with the constructor template, the trap kind and the scan range.

The pager tests `TestMissionDialogueShowsPagesByNumber` and `TestTownDialogueShowsPagesByNumber` feed a message with a missing page number, one with a repeated number and one written out of order. Both panels show pages by number from the first accepted tag and end at the first missing number. The town panel also shows `Nothing to say` and then page 2 for a message without page 1. The mission panel opens no notice for such a message (`openDialogue`, `pkg/game/world.go`), where DLG-PAGES-091 says the original shows `Nothing to say` and then page 2. That difference is returned, not changed.

Release tests ran EN then RU, twelve per root, all passing. Every installed map keeps its bytes through the save form (38 EN, 34 RU), and every field of every type-9 record set to its own value saves byte-equal (792 EN and 334 RU records, none read-only). `TestReleaseEditorNewTrapOnANewMapCastsInTestPlay` adds a trap without a template on a new map, exports it with F5 and sees Lightning cast at cell (47,40), tick 63, on both roots. `TestReleaseEditorOffAnchorCastingRecordEditsAndCopies` edits and copies `Beast.ALM` record 0 (EN, structure 1026, anchor one cell away) and `FORESTER.ALM` record 0 (RU, structure 38). Story 1514's placed-trap test still casts at (24,63), tick 54. Of 53 frames per root, two change against main `00c02a4c`: `cast-add.png` (the Add window's new title, template label, choices and steps) and `keys.png` (the F3 help line). The mode table's help column changes in 46 rows for the same line.

Loss control: a constructor that writes 1 at `+0x00` fails `TestCellSpellConstructorRecords` and `TestEditorCellSpellsAddWithoutATemplate`; a structure id lookup off by one fails five cell-spell editor tests. Both restore from the implementation commit. Deleting the object alone, without its records, fails `TestEditorObjectDeleteTakesItsCellSpells`; it restores from the correction commit.

## Open debt

The mission panel's missing-page-1 difference from DLG-PAGES-091 is open. A new trap's source and target start at its cell; the original takes them from the dialog's edits, whose start values are not claimed. What the game does with the scan range at run time is Unknown (ALM-T9CAST-333). This editor story counts for no release or audit. The original's delete also matches a kind-4 or kind-8 entry at cell 0,0 (ALM-EDITDEL-299 item 3 tests no cell); our delete keeps item recipes, and whether a shipped item recipe carries kind 4 or 8 with an object's id was not counted. When two objects share an id, deleting one also deletes the records the other still binds, as the original does. DIV-4047 is unused.
