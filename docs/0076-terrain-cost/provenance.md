## Ours by choice

| Spec anchor | The choice | Why it is ours, and what it would take to change |
|---|---|---|
| FR-1 | **An unnamed cost plane materialises at a uniform 8, an unnamed height plane at zero.** | The original always has both planes; a world with neither is not a state it can reach, so nothing is being reproduced. The value is chosen so that a world built without terrain behaves *exactly* as this build did before the planes existed: a uniform cost is order-equivalent to the flat constant the search charged, and a mean of 8 is the number the rate law's own zero-mean substitute already produced. Changing it changes every such world's rates. |
| FR-1 | **Both planes accept every byte value, including 0 and 255.** | Consistent with how this package already treats speed, health and the attack numbers: refuse only what the package cannot itself produce. A cost of 0 is a free step and is a state a caller may build, though no map derivation yields one. |
| FR-1 | **No flag records whether a plane was named.** | The block plane already works this way. Two representations of "absent" would be two things to keep in agreement, and the digest can see only one of them. |
| FR-4 | **A transit with an endpoint outside the world's bounds composes its rate from four zeros.** | A search may begin from a cell off the map — that is existing, deliberate behaviour — so the rate call site can be handed one, and the original has no such state to copy: its planes cover everything. Zeros are chosen over the planes' own out-of-range answer because zero is neutral for a height *difference* and is **not** neutral for a cost *level*: reading one endpoint as zero cost would halve the mean and give such a transit a rate the pre-story build did not, which is exactly what FR-1a forbids. Four zeros are what the law received before either plane existed. |
| FR-3 | **A route walk is bounded by the world's in-bounds cell count.** | The original bounds it too, at a literal 1000 steps, and discards the whole route past it (`MOVE-ROUTE-004`) — so a bound is faithful and only its size is ours. The cell count is chosen because it is *provably* unreachable while every cost on the walk is positive: the label falls strictly at each step, so a walk visits a strictly decreasing sequence and cannot outlast the cells. That makes the guard incapable of moving any behaviour FR-1a covers, which the decoded 1000 could not be shown to be. The decoded value is not reproduced, and the spec discloses that. |
| FR-1a | **The default cost must be EVEN, and not merely equal to the substitute.** | The exactness FR-1a claims needs `(c, c + c>>1)` proportional to `(2, 3)`, which holds precisely when `c` is even; at 8 both arms scale by 4. Deriving the default from the rate substitute keeps one number where there would be two, but the two answer to different constraints, so the evenness is written down rather than left implied. |
| FR-5 | **Strip groups 13-15 are rejected rather than reproduced.** | There is nothing to reproduce: the original reads uninitialised heap. Rejecting keeps the derivation a total, deterministic function of the tile word. Disclosed in the spec's *Divergences*. |
| FR-5 | **The ten class scalars are compiled in rather than read from a map registry.** | A reader for that registry section does not exist in this tree, and building one changes no output today because the values would be the same values. Same trade the rate multiplier already makes, from the same file's other section. |
| FR-9 | **A previous byte form is refused, not migrated.** | The package's standing rule for every version before this one. Here it is structural twice over: the record offsets move, and a form carrying no cost plane would decode to a world whose digest is not the digest of the world it was cut from. |
| FR-8 | **The two derivations share one classifier rather than keeping two readings of one rule.** | Engineering, not fidelity: the block derivation's own note already says the census must count the rule the plane is built from and not a second reading of it. The cost of the choice is that a block-plane regression becomes possible, which is why FR-8 is a requirement with a corpus measurement behind it rather than an assumption. |

## Open

| What | Why it is left open |
|---|---|
| The six cell-record pointers that quadruple a cost byte in place. | Published **Unknown**: what fills them, and therefore whether the cost-×4 arm is live at all. The instrument that would find a writer is named at source and has not been run. This tree carries no cell records, so nothing here depends on the answer. |
| The runtime bit-5 quartering of a cost byte, and the per-cell record hash it is gated on. | Decoded, and out of this story's consumers: it reaches the duration read and never a path cost. |
| Whether other readers of the cost plane exist in the original. | `TERR-COST-052` grades this **Unknown** and says why the usual instrument cannot answer it: the plane's base displacement is zero, so a displacement sweep structurally cannot see its readers. The row records that a later experiment found six more readers exactly there. Any further reader would be a further consumer this story has not implemented. |
| Which registry key would fill the class scalars at load, and the reader for it. | The section and its framing are decoded; no reader is built. See *Ours by choice*. |
| The type-2 naming of the height plane. | Graded Medium at source. A wrong naming would put the tilt on the wrong plane, and the two candidates are separated only by a loader error string and by a swap test on blocking. |

## Removed

| Statement | Why it was dropped |
|---|---|
| "The cost plane is cleared to 1 before the walk." | True of the original's world constructor and unobservable: the ingest then writes every in-bounds cell, and this tree's planes are exactly the in-bounds cells. Carrying it would have described an initial state nothing can read. |
| "A blocked cell has no cost." | Refuted by the source — the cost byte is written unconditionally for every cell including blocked ones. The tempting shortcut of leaving blocked cells at a sentinel would have been visible only through a customised map that unblocks one. |
| "Water costs the water class's scalar." | The natural reading, and wrong: the water arm returns the classifier's entry literal and never reaches the scalar table. Indistinguishable on shipped data, since both are 8. |
| "A diagonal costs one and a half times an orthogonal step." | True only as an untruncated ratio. Kept as the truncating form, because the two disagree at every odd cost byte and the shipped alphabet contains odd values. |
| An 8-cell border term in the cost derivation. | The border stamp is a block-plane arm and writes no cost byte. |
