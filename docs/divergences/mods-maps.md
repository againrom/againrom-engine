| DIV-4009 | mods / an Againrom-only map: the undying action and the health-below condition | Owner (BACKLOG T7): a map script may keep a unit from dying and react when its health falls below a chosen value; the original has no such rule | `HERO-DEATH-026`: the death arm is taken on health <= 0; `HERO-DECAY-069`: a body not torn down loses health every fourth full tick while it is strictly negative; `HERO-DWELL-065`: teardown after the dwell at health <= -10; `HERO-HEALTH-032`: health is a signed 16-bit field. `ALM-TRIG-045`, `ALM-TRIG-046`: a node is an opcode with ten typed parameters. `TRIG-BIND-010`: a check opcode 23..0x10001 is built when its references resolve; `TRIG-BINDORDER-101`: the binder numbers conditions and actions in file order, a built condition takes the next register and an unbuilt one reads register 0; `TRIG-COND-003`: such a check writes no register; `TRIG-STORE-002`: registers start at 0; `TRIG-ACT-004`: an action opcode 35..0x10001 logs "Script: Bad instant" and returns. `TRIG-EVAL-001`: one trigger pass per full tick. `ALM-SEC-003`: an ALM holds exactly ten sections of fixed types | Action 0x4100 "Set undying" (unit, state 1 or 0) and check 0x4101 "Health below" (unit, X in -32768..32767) are rows of the one node table, run by the one trigger evaluator. An undying unit is alive at any health down to -32768: it takes no death arm, no live decay and no dwell; it acts, is attacked and healed; target pickers that rank by health rank it as a body at that health. Clearing the state at health <= 0 runs the ordinary death transition in that pass. Health-below writes 1 while health < X, else 0, each trigger pass. The state is bit 1 of the entity record's always-hits byte and `Undying` in the SAV native actions leaf, both absent when no unit is undying. An Againrom-only map is one whose script holds either opcode; the mark is derived and adds no byte. Under the cited claims the original builds the check, which stays 0, and logs and skips the action, so a trigger waiting for health-below never fires and no unit is undying | DEVIATION | Owner direction; behaviour the original lacks | An owner decision on a written mark, a ROM2 form, or another undying rule | ACCEPTED |
